খালি folder থেকে পুরো API, ১৬টা ধাপে। প্রতিটা ধাপে: কী করবে, কেন, কোন command, কোন file (নতুন না আপডেট), পুরো code, আর চালিয়ে কী output দেখবে। প্রতিটা ধাপ আমি নিজে চালিয়ে যাচাই করেছি, শেষে ১১টা test pass।

Stack: Node.js 20+ · Express 5 · TypeScript · PostgreSQL (pg) · Redis (ioredis) · Zod · JWT · bcryptjs · Vitest + Supertest
